# تطبيق مطعم (Restaurant App) باستخدام Flutter

هذا المشروع هو تطبيق مطعم بسيط تم إنشاؤه باستخدام إطار عمل **Flutter**، ويهدف إلى تلبية المتطلبات المذكورة في وثيقة المشروع. تم تصميم هيكل المشروع ليكون **منظماً وواضحاً**، مما يسهل عملية التطوير والصيانة المستقبلية.

## متطلبات المشروع المُنفذة

تم تنفيذ الميزات الأساسية التالية بناءً على الوثيقة المقدمة:

1.  **الصفحة الرئيسية:** تعرض قائمة الوجبات مع إمكانية التصفية حسب الفئة.
2.  **صفحة تفاصيل الصنف:** تعرض تفاصيل الوجبة مع إمكانية إضافتها إلى سلة الطلبات.
3.  **صفحة سلة الطلبات:** تسمح بعرض الوجبات المختارة، تعديل الكميات، وإتمام عملية الطلب.
4.  **صفحة الملف الشخصي/الطلبات السابقة:** تحتوي على تبويبين: معلومات المستخدم الشخصية، وقائمة بالطلبات السابقة.

## قاعدة البيانات والتقنيات المستخدمة

تم الاعتماد على **Supabase** كخلفية برمجية (Backend) وقاعدة بيانات للمشروع، وتم تشغيلها محلياً باستخدام **Docker**.

### استخدام Supabase مع Docker كقاعدة بيانات محلية
بدلاً من الاعتماد الكلي على السحابة أثناء التطوير، تم استخدام نسخة محلية من Supabase تعمل داخل حاويات Docker. يوفر هذا النهج بيئة تطوير متكاملة تحاكي الواقع تماماً.

### مميزات استخدام Docker لتشغيل قاعدة البيانات محلياً:
*   **الاستقلالية:** تتيح للمطور العمل دون الحاجة لاتصال دائم بالإنترنت.
*   **السرعة:** استجابة قاعدة البيانات تكون أسرع بكثير لأنها تعمل على نفس الجهاز المحلي.
*   **التحكم الكامل:** إمكانية إدارة الجداول، الصلاحيات، والمستخدمين بسهولة عبر واجهة Supabase المحلية.
*   **سهولة الإعداد:** بفضل Docker، يمكن تشغيل كامل البيئة (PostgreSQL, Auth, Storage) بأمر واحد فقط، مما يضمن تطابق بيئة التطوير لدى جميع المبرمجين.
*   **الأمان والخصوصية:** تبقى البيانات الحساسة أثناء التطوير داخل الجهاز المحلي ولا ترفع إلى السحابة إلا عند الجاهزية.

## هيكل المشروع

تم تقسيم المشروع إلى مجلدات واضحة لتنظيم الكود وفقاً لمبدأ **الفصل بين الاهتمامات (Separation of Concerns)**:

| المجلد | الوصف |
| :--- | :--- |
| `lib/models` | يحتوي على نماذج البيانات (Classes) مثل `Meal` و `CartModel`. |
| `lib/screens` | يحتوي على الشاشات الرئيسية للتطبيق (Pages) مثل `HomeScreen` و `CartScreen`. |
| `lib/services` | يحتوي على الخدمات التي تتعامل مع البيانات أو المنطق الخارجي، مثل `DataService` و `AuthProvider`. |
| `lib/widgets` | يحتوي على المكونات المرئية القابلة لإعادة الاستخدام (Reusable UI Components) مثل `MealItemWidget`. |

## المكونات الرئيسية للكود

| الملف | الوصف |
| :--- | :--- |
| `lib/main.dart` | نقطة الدخول للتطبيق، ويحتوي على إعداد `ChangeNotifierProvider` لإدارة حالة سلة المشتريات والمصادقة. |
| `lib/models/meal.dart` | تعريف نموذج بيانات الوجبة. |
| `lib/models/cart_model.dart` | نموذج إدارة حالة سلة المشتريات والطلبات السابقة. |
| `lib/services/auth_provider.dart` | يدير عمليات تسجيل الدخول وإنشاء الحساب عبر Supabase. |
| `lib/services/data_service.dart` | يتعامل مع جلب بيانات الوجبات من قاعدة بيانات Supabase. |
| `lib/screens/home_screen.dart` | شاشة عرض قائمة الوجبات مع التصفية. |
| `lib/screens/profile_screen.dart` | شاشة الملف الشخصي والطلبات السابقة. |
